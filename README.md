**Martial Systems LLC** Chrome extension: keep more than one text selection (including across tabs) and copy them together.

**We do not save your data.** Selected text is not uploaded to us and is not written to disk.

**We do not publish source code.** This repository is the public landing page. It is not the Chrome extension.

**Do not use the green Code button or “Download ZIP” on this page.** That archive is only this landing page. It has no `manifest.json`, so Chrome will say the manifest is missing.

**Download the extension from [Releases](https://github.com/martialsystems/select-more/releases/latest).** The file is named `select-more-chrome-*.zip`.

## Install from a Release

1. Open the latest [Release](https://github.com/martialsystems/select-more/releases/latest)
2. Download **`select-more-chrome-*.zip`** (not “Source code (zip)”, not this repo’s Code / Download ZIP)
3. Unzip it. You should see `manifest.json`, `popup.html`, `src/`, and `icons/`
4. `chrome://extensions` → Developer mode on
5. **Load unpacked** → pick that unzipped folder (the one that contains `manifest.json`)

Chrome will not install a `.zip` as an unpacked extension. Unzip first, then load the folder. If Chrome says the manifest is missing, you loaded the landing-page archive instead of the Release zip.
