# Select More

**Martial Systems LLC** Chrome extension: keep more than one text selection (including across tabs) and copy them together.

**We do not save your data.** Selected text is not uploaded to us and is not written to disk.

**We do not publish source code.** This repository is the public landing page and [Releases](https://github.com/martialsystems/select-more/releases). Download the zip. Do not expect a clone to contain the implementation.

## Install from a Release

1. Open the latest [Release](https://github.com/martialsystems/select-more/releases/latest)
2. Download the `.zip`
3. Unzip it
4. `chrome://extensions` → Developer mode on
5. **Load unpacked** → pick the folder that contains `manifest.json`

Chrome will not install the zip as a Store extension. Unzip, then load the folder.
